# CLAUDE.md

Заметки по проекту для Claude Code. Здесь только то, что неочевидно из кода.

## Команды

```bash
npm run dev      # Vite dev-сервер, порт 5173
npm run build    # tsc -b + vite build
npm run lint     # eslint
```

Для визуальной проверки есть `.claude/launch.json` (конфигурация `dev`) — запускать сервер
через preview_start, а не через Bash.

## Главное про стили: @theme переопределяет шкалу Tailwind

Проект на Tailwind v4, все токены заданы в `@theme` внутри [src/main.css](src/main.css).
**Стандартная шкала размеров переопределена**, поэтому привычные значения Tailwind тут врут:

| Класс       | В этом проекте | В стоковом Tailwind |
| ----------- | -------------- | ------------------- |
| `text-xs`   | 1rem           | 0.75rem             |
| `text-sm`   | 1.125rem       | 0.875rem            |
| `text-md`   | 1.875rem       | не существует       |
| `text-lg`   | 2rem           | 1.125rem            |
| `text-xl`   | 3.25rem        | 1.25rem             |
| `text-2xl`  | 5.25rem        | 1.5rem              |
| `rounded-*` | 0.375/0.5/0.625rem | 0.25/0.375/0.5rem |
| `leading-normal` | 1.4       | 1.5                 |

`leading-free` (1.6) — кастомный, стокового аналога нет.

Правило при вёрстке: **если переменная есть в `@theme` — использовать её**, если нет —
брать стандартную из Tailwind. Размеры задавать в rem. Промежуточные значения из макета
(15px, 13px) в шкалу не входят — писать как `text-[0.9375rem]`, `text-[0.8125rem]`.

### Цвета

`black` `#080a14` (фон), `light-blue` `#dcdfe9` (основной текст), `grey-blue` `#767fa0`
(вторичный текст), `grey` `#c3c7db`, `dark-blue` `#12172a` (текст на белых кнопках),
`grey-60` / `grey-160` — полупрозрачные белые для рамок.

Шрифты: `font-heading` (Marck Script, заголовки-надписи), `font-title` (Playfair Display,
заголовки сцен), `font-text` (Inter, весь остальной текст).

### Анимации

`animate-fade-up` и `animate-scale-in` объявлены через `--animate-*` в `@theme`.
В конце main.css есть блок `prefers-reduced-motion`, который гасит их вместе с
`animation-delay` — без сброса задержки кнопки выбора остались бы невидимыми
(`animation-fill-mode: both`).

Экраны переигрывают анимацию через `key={scene.id}` — без ключа React переиспользует
DOM-узел и анимация проигрывается только при монтировании.

## Адаптив

Используются два брейкпоинта:

- `sm` (640px) — белые кнопки становятся `w-full` и в колонку (`width="fullOnMobile"` у
  `Button`), карточки глав растут со 180px до 280px, паддинг `Main` уменьшается.
- `lg` (1024px) — шапка игры переключается между колонкой и строкой. Ниже 1024px
  StatsBar уезжает под навигацию, иначе `justify-between` выталкивает его за экран.

## Архитектура

Роутера нет — экраны переключаются через `useState<Screen>` в [src/app/App.tsx](src/app/App.tsx).
Общая обёртка страницы (фон, шрифт, `min-h-screen`) живёт там же; страницы её не дублируют.

Состояние игры — один контекст ([src/state/gameProvider.tsx](src/state/gameProvider.tsx)),
доступ через хук `useGame()`. Сохранение в localStorage под ключом `quiet-good-life-save`.

Контент полностью декларативный, в [src/data/gameData.json](src/data/gameData.json).
Движок в `src/engine/` его интерпретирует:

- `conditions.ts` — фильтрует доступные варианты (`flag`, `stat_gte`, `has_item`)
- `effects.ts` — применяет последствия выбора (`set_flag`, `change_stat`, `add_item`, `remove_item`)
- `gameEngine.ts` — переходы между сценами, разблокировка глав, подбор картинки

Логику развилок держать в JSON, а не в компонентах.

## Грабли

**Пути к картинкам.** В `gameData.json` должно быть `/images/…`, а не `/public/images/…`.
Второй вариант работает в `npm run dev` (Vite отдаёт файлы с диска) и отваливается 404 в
проде, потому что `public/` копируется в корень `dist/`. Ловится только сборкой.

**Строгий tsc.** Включены `noUnusedLocals` и `noUnusedParameters`, поэтому неиспользуемая
переменная или параметр валит `npm run build`, а не только линт. Для намеренных заглушек —
префикс `_`.

**Высота игрового экрана.** Не вешать `h-screen` + `overflow-hidden` на игровой экран:
на низких окнах последние варианты выбора обрезаются без скролла и игру нельзя пройти.
Сейчас там `flex grow flex-col`, страница скроллится штатно.

**Картинки глав уже содержат название главы**, нарисованное внутри. Плашку с подписью
поверх баннера не добавлять — будет дублирование.
