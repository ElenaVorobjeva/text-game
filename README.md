# Тихий хороший день

Небольшая текстовая игра о мягком ритме жизни, простых решениях и спокойном дне.

Игрок проходит три главы, выбирая реплики и действия. Каждый выбор меняет три характеристики —
**Забота**, **Связь**, **Покой** — и от их соотношения зависит, какой концовкой закончится день.

## Стек

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4 (токены дизайн-системы в `@theme`)

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Остальные команды:

```bash
npm run build    # проверка типов + продакшен-сборка в dist/
npm run preview  # локальный просмотр собранной версии
npm run lint     # eslint
```

## Как устроен контент

Вся игра описана декларативно в `src/data/gameData.json` — код сцен не содержит.
Сейчас это 3 главы по 3 сцены и 4 концовки.

Сцена состоит из текста и списка вариантов. У варианта есть `nextSceneId`, необязательные
`conditions` (когда вариант вообще показывать) и `effects` (что произойдёт при выборе):

```json
{
  "id": "chapter1_scene1",
  "chapter": 1,
  "title": "Пробуждение",
  "text": "Утро мягко просачивается сквозь занавески…",
  "choices": [
    {
      "id": "c1_s1_choice1",
      "text": "Остаться в постели и прислушаться к утру",
      "nextSceneId": "chapter1_scene2",
      "effects": [
        { "type": "change_stat", "stat": "calm", "delta": 1 },
        { "type": "set_flag", "key": "started_slowly", "value": true }
      ]
    }
  ]
}
```

**Условия:** `flag` (значение флага), `stat_gte` (характеристика не ниже порога),
`has_item` (предмет в инвентаре). Вариант без условий доступен всегда.

**Эффекты:** `change_stat`, `set_flag`, `add_item`, `remove_item`.

**Концовки** — это сцены с `"chapter": 0`, `"isEnding": true` и пустым списком выборов.
Развилка к ним собрана в последней сцене третьей главы: три «сильные» концовки открываются
условием `stat_gte` со значением 5 по соответствующей характеристике, а `ending_balanced`
доступна всегда и работает как запасной вариант.

Чтобы добавить сцену, достаточно дописать объект в `scenes` и сослаться на его `id` из
`nextSceneId` любого варианта — трогать компоненты не нужно.

## Сохранения

Прогресс пишется в localStorage под ключом `quiet-good-life-save` после каждого выбора.
При наличии сохранения главное меню показывает «Продолжить», иначе — «Старт».
